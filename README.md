# Validador de CPF

## Objetivo
Este projeto tem como objetivo validar um número de CPF informado pelo usuário, informando se ele é válido ou inválido.

## Tecnologias utilizadas
- Java
- Swing (interface gráfica)

## Como funciona
O usuário digita um CPF na interface e o sistema:
1. Remove caracteres não numéricos
2. Verifica se possui 11 dígitos
3. Calcula os dígitos verificadores
4. Exibe o resultado na tela

## Como executar
1. Abrir o projeto no IntelliJ
2. Executar a classe TelaCPF
3. Inserir um CPF e clicar em "Validar"

## Estrutura
- TelaCPF.java: Interface gráfica
- ValidadorCPF.java: Lógica de validação
